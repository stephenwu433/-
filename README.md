# 东鹏海外项目 AI 办公协同助手

基于 **FastGPT** 构建的东鹏控股海外业务 AI 知识库与协同助手，面向海外项目拓展场景，帮助销售快速整理信息、生成材料、推动协作与沉淀经验。

> 本系统**不替代**销售进行产品决策，而是作为销售与跨部门协作的 AI 助手。

---

## 项目是什么

建设东鹏海外业务 AI 知识库，接入产品资料、海外案例、认证文件、品牌素材、报价规则、交付周期和常见问题等内容。销售人员输入客户邮件、会议记录或项目需求后，AI 自动完成信息提取、摘要生成、案例推荐、英文材料初稿、跨部门协同任务输出，以及会议纪要与商机风险整理；审核后的优秀方案可沉淀为团队知识，并与 CRM / 现有业务系统对接，实现「客户信息有记录、销售动作有提醒、项目资料可复用」。

---

## 面向谁使用

| 角色 | 使用方式 |
|------|----------|
| 海外销售 / 国际业务 | 主用户：整理客户需求、生成方案与邮件、跟进商机 |
| 设计团队 | 接收协同任务，复用历史案例与方案素材 |
| 产品团队 | 补充产品资料、认证与选型建议 |
| 供应链 / 工程 | 对齐交期、交付规则与工程约束 |
| 财务（协同） | 参与报价与预算相关协同事项 |

## 场景痛点

东鹏控股海外市场覆盖国家多、产品品类多，海外项目通常涉及瓷砖、岩板、卫浴、新材及整装方案。销售人员需要反复处理客户邮件、会议纪要、产品资料、历史案例、认证文件、报价需求和内部协同事项。

当前主要问题：

1. **需求分散**：客户需求散落在邮件、聊天记录和会议纪要中，整理成本高  
2. **检索低效**：产品资料、海外案例、认证文件和价格政策难以及时找到  
3. **协同复杂**：酒店、商业综合体等项目需频繁协调设计、产品、供应链和财务  
4. **多语种耗时**：英文或其他语言的方案、邮件和资料准备周期长  
5. **经验难沉淀**：优秀销售经验难以复用，新员工与跨区域团队上手慢  
6. **跟进易遗漏**：商机跟进依赖个人记忆，易出现漏跟与响应不及时  

---

## 解决方案

### 1. 海外业务 AI 知识库

接入并结构化管理：

- 产品资料（瓷砖、岩板、卫浴、新材、整装）  
- 海外历史项目案例  
- 认证文件与品牌素材  
- 报价规则、交付周期与常见问题  

### 2. 销售侧 AI 能力（基于 FastGPT 应用 / 工作流）

销售输入客户邮件、会议记录或项目需求后，系统可自动：

| 能力 | 说明 |
|------|------|
| 关键信息提取 | 国家、项目类型、面积、预算、交期等 |
| 需求摘要 | 生成摘要与待确认问题清单 |
| 案例与资料推荐 | 匹配历史案例及相关产品资料，供销售审核 |
| 多语种材料生成 | 英文项目介绍、客户邮件、方案初稿 |
| 协同任务拆解 | 输出产品、设计、供应链、财务等部门待办 |
| 会议与商机管理 | 整理纪要、跟进计划与商机风险 |
| 知识沉淀 | 将审核后的优秀方案回写入团队知识库 |

### 3. 系统对接

与 CRM 或现有业务系统对接，保证客户信息有记录、销售动作有提醒、项目资料可复用。

---

## 预期价值

- 减少查资料、整理邮件、制作方案与撰写跟进内容的重复劳动  
- 目标将复杂海外项目前期响应时间从**数天缩短至数小时**  
- 提高跨部门协同效率，减少信息遗漏与重复沟通  
- 降低对个人经验的依赖，加速新员工上手  
- 沉淀东鹏海外市场知识，支撑品牌本地化、方案化与数字化出海  
- 后续可复制到国内工程、整装、卫浴和大客户销售场景  

---

## 需要支持

推进本项目需要：

1. **数据**：海外产品资料、历史项目案例、认证文件、品牌素材、报价及交付规则等  
2. **业务参与**：国际销售、设计、产品、供应链和财务人员参与业务梳理与试用  
3. **系统接口**（条件允许时）：CRM、知识库或内部文件系统的接口支持

## 技术底座：FastGPT

本项目采用 [FastGPT](https://github.com/labring/FastGPT) 作为 AI 应用与知识库平台，用于：

- 搭建东鹏海外知识库（文档上传、向量检索、权限管理）  
- 配置销售助手应用与多步工作流（提取 → 摘要 → 推荐 → 生成 → 协同）  
- 对接大模型 API、后续 CRM / 文件系统插件

## 快速开始

```bash
# 1. 进入部署目录（见 docs/DEPLOYMENT.md）
cd deploy

# 2. 推荐：官方交互式脚本（Linux / macOS / WSL）
FASTGPT_DEPLOY_BASE_URL=https://doc.fastgpt.cn \
  bash <(curl -fsSL https://doc.fastgpt.cn/deploy/install.sh)

# 3. 浏览器访问 http://<服务器IP>:3000
#    用户名: root
#    密码: 安装脚本生成的 DEFAULT_ROOT_PSW
```

部署完成后，请按 `docs/DEPLOYMENT.md` 中「东鹏海外知识库初始化」与「销售助手应用配置」章节完成业务适配。
