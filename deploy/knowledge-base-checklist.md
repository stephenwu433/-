# 东鹏海外知识库初始化清单

部署 FastGPT 后，按此清单完成业务侧知识库建设。

## A. 知识库创建

- [ ] `DP-海外产品资料`（瓷砖 / 岩板 / 卫浴 / 新材 / 整装）
- [ ] `DP-海外历史案例`（按国家、项目类型标注）
- [ ] `DP-认证与合规`
- [ ] `DP-品牌与方案素材`
- [ ] `DP-报价与交付规则`（权限隔离）
- [ ] `DP-FAQ与话术`

## B. 首批数据导入（PoC）

- [ ] 各品类核心产品说明书 ≥ 1 套
- [ ] 典型海外案例 ≥ 5 个（含酒店或商业综合体）
- [ ] 主要目标市场认证文件样本
- [ ] 品牌介绍与英文方案模板
- [ ] 报价/交期规则摘要（脱敏或权限受控）
- [ ] 高频 FAQ ≥ 20 条

## C. 应用与工作流

- [ ] 创建应用：`东鹏海外销售协同助手`
- [ ] 挂载对应知识库
- [ ] 配置系统提示词（禁止擅自承诺价格/交期）
- [ ] 配置工作流：提取 → 摘要 → 检索 → 生成 → 协同任务
- [ ] 配置团队成员：销售、设计、产品、供应链、工程试用账号

## D. 验收（对照痛点）

- [ ] U1 英文客户邮件信息提取
- [ ] U2 案例/产品检索命中
- [ ] U3 英文项目介绍初稿
- [ ] U4 跨部门协同任务清单
- [ ] U5 会议纪要与跟进计划
- [ ] U6 价格敏感问题人工确认提示

## E. 需要业务方提供

- [ ] 海外产品资料包
- [ ] 历史项目案例包
- [ ] 认证文件
- [ ] 品牌素材
- [ ] 报价及交付规则
- [ ] 国际销售 / 设计 / 产品 / 供应链 / 财务试用名单
- [ ] （可选）CRM / 文件系统接口说明
