# FastGPT 部署指南（适配东鹏海外 AI 协同助手）

本文说明如何部署 FastGPT，并完成与「东鹏海外项目 AI 办公协同助手」的业务适配。

官方文档参考：[FastGPT Docker Compose 部署](https://doc.fastgpt.cn/zh-CN/docs/self-host/deploy/docker)

---

## 1. 部署目标（与本项目对齐）

部署完成后应具备：

| 能力 | 用途 |
|------|------|
| FastGPT Web 控制台 | 配置知识库、应用、工作流、团队权限 |
| 向量知识库 | 承载产品资料、海外案例、认证、报价规则等 |
| 销售助手应用 | 面向海外销售的日常入口 |
| 工作流 | 实现「提取 → 摘要 → 推荐 → 生成 → 协同」链路 |
| （可选）插件 / API | 对接 CRM、文件系统 |

建议先在内网或测试环境完成 PoC，再切换生产域名与正式模型密钥。

---

## 2. 环境要求

| 项目 | 建议 |
|------|------|
| 操作系统 | Linux（推荐）/ macOS / Windows WSL |
| Docker | 已安装 Docker Engine |
| Docker Compose | **≥ 2.17** |
| 资源（PoC） | 建议 ≥ 4 核 CPU、8GB 内存、50GB 磁盘 |
| 资源（生产） | 建议 ≥ 8 核、16GB 内存，按并发与知识库规模扩容 |
| 网络 | 可拉取模型 API（OpenAI / 国产大模型等）；国内可用阿里云镜像源 |
| 端口 | `3000`（主站）、`9000`（MinIO，如启用）、`3003`（MCP）、`3006`（Sandbox Proxy，视版本） |

## 3. 推荐部署方式：官方交互式脚本

在 Linux / macOS / Windows WSL 执行：

```bash
FASTGPT_DEPLOY_BASE_URL=https://doc.fastgpt.cn \
  bash <(curl -fsSL https://doc.fastgpt.cn/deploy/install.sh)
```

脚本会引导完成：

1. 检测 Docker / Compose 环境  
2. 选择向量库方案（常用 **PgVector**）  
3. 选择镜像源（国内推荐阿里云 `cn`，海外可用 `global`）  
4. 配置访问地址 `FE_DOMAIN`（用户实际访问 URL，如 `https://dongpeng-ai.example.com` 或 `http://内网IP:3000`）  
5. 生成随机 root 密码，并写入 `docker-compose.yml`  

生成完成后，在对应目录启动：

```bash
docker compose --profile prepull pull
docker compose up -d
```

### 访问

- 地址：`http://<服务器IP>:3000` 或已配置域名  
- 用户名：`root`  
- 密码：脚本终端输出的 `DEFAULT_ROOT_PSW`（亦写在 compose 环境变量中）

> **重要**：`FE_DOMAIN` 必须填写用户真实访问的完整地址（含协议与端口），不要填容器内部地址。生产环境建议使用 HTTPS 域名。

## 4. 备选：手动下载 Compose 部署

适合离线、固定版本或无法跑交互脚本的环境。

### 4.1 下载 compose 文件（以 PgVector + 国内镜像为例）

```bash
mkdir -p ~/dongpeng-fastgpt && cd ~/dongpeng-fastgpt

# 国内镜像源（阿里云）
curl -fsSL -o docker-compose.yml \
  https://doc.fastgpt.cn/deploy/docker/cn/docker-compose.pg.yml

# 如官方要求配套 config.json，请按文档同页下载至同级目录
```

全球镜像源可将路径中的 `cn` 改为 `global`。

### 4.2 修改关键环境变量

编辑 `docker-compose.yml` 中 `fastgpt-app`（或等价服务）相关变量，至少确认：

| 变量 | 说明 | 东鹏项目建议 |
|------|------|----------------|
| `FE_DOMAIN` | 前端对外访问地址 | `https://dongpeng-overseas-ai.公司域名` |
| `DEFAULT_ROOT_PSW` | root 初始密码 | 强密码，勿用默认 `1234` 上生产 |
| 模型相关密钥 | 对接 LLM / Embedding | 使用公司统一申请的 API Key |

同时建议修改 Mongo、Postgres、MinIO、Redis 等默认账密后再启动。

### 4.3 启动

```bash
docker compose --profile prepull pull
docker compose up -d
docker compose ps
```

查看日志：

```bash
docker compose logs -f fastgpt-app
```

## 5. 生产加固清单

部署到东鹏正式环境前建议完成：

1. **域名与 HTTPS**：Nginx / 网关反向代理 `3000`，证书有效  
2. **修改全部默认密码**：数据库、对象存储、root 账号  
3. **网络隔离**：仅开放必要端口；内网优先  
4. **备份**：Mongo / Postgres 定期备份；知识库文件与 MinIO 卷备份  
5. **模型配额**：为海外销售并发预留 TPM / RPM  
6. **审计与权限**：按「销售 / 设计 / 产品 / 供应链 / 工程 / 管理员」分团队或角色  
7. **数据分级**：报价政策、认证文件等敏感资料限制可见范围

## 6. 东鹏海外知识库初始化（业务适配）

登录 FastGPT 后，建议按以下结构创建知识库（名称可按公司规范调整）：

| 知识库名称 | 内容 | 主要使用者 |
|------------|------|------------|
| `DP-海外产品资料` | 瓷砖、岩板、卫浴、新材、整装产品说明 | 销售、产品 |
| `DP-海外历史案例` | 酒店、商业综合体等项目案例 | 销售、设计 |
| `DP-认证与合规` | 各国认证文件、合规说明 | 销售、工程 |
| `DP-品牌与方案素材` | 品牌介绍、方案模板、图片文案 | 销售、设计 |
| `DP-报价与交付规则` | 价格政策、交期、交付约束（严格权限） | 销售、供应链、财务 |
| `DP-FAQ与话术` | 常见问题、优秀跟进话术 | 销售、新人 |

### 导入建议

1. 优先导入已脱敏、已审核的 PDF / Word / Markdown  
2. 按「国家 / 品类 / 项目类型」在文档元数据或目录命名中体现，便于检索  
3. 报价与认证类资料单独库 + 权限隔离  
4. 每次导入后做抽检问答（见下文验收用例）

## 7. 销售助手应用与工作流配置

### 7.1 应用：`东鹏海外销售协同助手`

建议系统提示词方向（可按试用反馈迭代）：

```text
你是东鹏控股海外业务 AI 办公协同助手，服务对象为海外销售、国际业务、
设计、产品、供应链及工程团队。你不替代销售做最终产品决策，而是帮助：
整理客户信息、生成材料初稿、推动跨部门协作、沉淀可复用经验。

输出要求：
1) 先提取：国家、项目类型、面积、预算、交期等关键字段（未知则标注「待确认」）
2) 给出需求摘要与待确认问题清单
3) 基于知识库推荐相关历史案例与产品资料，并注明需人工审核
4) 可生成英文项目介绍 / 客户邮件 / 方案初稿
5) 拆解给设计、产品、供应链、财务的协同任务
6) 涉及价格、交期、承诺条款时，必须提示销售人工确认，不得擅自承诺
```

挂载知识库：至少挂载产品资料、历史案例、FAQ；报价库按权限决定是否挂载。

### 7.2 工作流（推荐拆成可维护节点）

```
输入（邮件/纪要/需求）
  → 关键信息提取（结构化）
  → 需求摘要 + 待确认问题
  → 知识库检索（案例 / 产品）
  → 英文材料生成（可开关）
  → 协同任务清单
  → （可选）商机风险与跟进计划
  → 输出汇总（供销售一键复制 / 导出）
```

每个节点使用固定输出模板，便于销售审核与跨部门转发。

### 7.3 协同任务输出模板示例

```markdown
## 协同任务
- [设计] ...
- [产品] ...
- [供应链] ...
- [财务] ...
- [工程] ...
## 风险与待确认
- ...
## 建议跟进
- 时间点 / 动作 / 责任人（待销售指定）
```

## 8. 与 CRM / 文件系统对接（后续）

条件具备时：

1. 在 FastGPT 中配置 HTTP 插件，调用 CRM 创建/更新线索、商机字段  
2. 将「审核通过的方案摘要」回写 CRM 附件或备注  
3. 内部文件系统通过 API / 同步任务定期更新知识库  
4. 跟进提醒可先由 CRM 完成，AI 负责生成提醒文案与待办清单  

PoC 阶段可先不做对接，用「人工复制到 CRM」验证业务价值。

## 10. 常见问题

**Q: 启动后无法访问？**  
检查 `3000` 端口、防火墙、`FE_DOMAIN` 是否与实际访问地址一致，以及 `docker compose ps` 各服务是否 healthy。

**Q: 知识库检索不准？**  
检查文档切分质量、Embedding 模型、是否导入错误库；对案例与产品文档补充清晰标题与国家/品类关键词。

**Q: 模型回复慢或失败？**  
检查 API Key、代理、配额；国内网络建议使用可达的模型服务商。

**Q: 如何升级 FastGPT？**  
按官方 Release / 文档更新镜像 tag，先备份数据库与卷，再在测试环境验证后滚动升级。
