# 东鹏海外项目 AI 办公协同助手 — 项目介绍

## 一句话定位

面向东鹏控股海外销售、国际业务、设计、产品、供应链及工程团队，打造服务于海外项目拓展的 **AI 办公协同助手**：不替代销售决策，而是帮助销售快速整理信息、生成材料、推动协作和沉淀经验。

---

## 项目背景

东鹏控股海外市场覆盖国家多、产品品类多。海外项目通常涉及：

- 瓷砖  
- 岩板  
- 卫浴  
- 新材  
- 整装方案  

销售日常需要反复处理：客户邮件、会议纪要、产品资料、历史案例、认证文件、报价需求与内部协同事项。信息分散、检索慢、协同重、多语种成本高，导致前期响应慢、经验难传承、商机易遗漏。

---

## 目标用户

| 优先级 | 用户群体 | 核心诉求 |
|--------|----------|----------|
| P0 | 海外销售 / 国际业务 | 快速读懂客户需求、出材料、跟进商机 |
| P1 | 设计 / 产品 | 获取协同任务与可复用案例、资料 |
| P1 | 供应链 / 工程 | 交期、交付与工程约束对齐 |
| P2 | 财务 | 报价与预算相关协同 |
| P2 | 新员工 / 跨区域团队 | 借助沉淀知识快速上手 |

---

## 场景痛点（真实业务问题与影响）

| 痛点 | 表现 | 业务影响 |
|------|------|----------|
| 需求分散 | 邮件、聊天、会议纪要多处散落 | 整理成本高，关键信息易漏 |
| 检索低效 | 产品、案例、认证、价格政策难找 | 响应慢，方案质量不稳定 |
| 协同复杂 | 酒店/商业综合体等项目多方协调 | 重复沟通，推进慢 |
| 多语种耗时 | 英文方案、邮件、资料需人工撰写 | 前期周期拉长 |
| 经验难沉淀 | 优秀做法留在个人 | 新人上手慢，区域能力不均 |
| 跟进依赖记忆 | 商机提醒靠个人 | 漏跟、响应不及时 |

---

## 解决方案

### 总体思路

以 **FastGPT** 为底座，建设「东鹏海外业务 AI 知识库 + 销售协同工作流」，并通过 CRM / 业务系统对接形成闭环。

```
客户邮件 / 会议纪要 / 项目需求
            │
            ▼
   ┌─────────────────────┐
   │  FastGPT 销售助手    │
   │  (知识库 + 工作流)   │
   └─────────────────────┘
            │
    ┌───────┼───────┬──────────┬──────────┐
    ▼       ▼       ▼          ▼          ▼
 信息提取  摘要与问题  案例推荐   英文材料   协同任务
    │       │       │          │          │
    └───────┴───────┴──────────┴──────────┘
                        │
                        ▼
              人工审核 → 知识沉淀 / CRM 记录
```

### AI 自动完成的事项

销售输入材料后，系统应能：

1. **提取关键信息**：项目国家、项目类型、面积、预算、交期等  
2. **生成需求摘要**与待确认问题清单  
3. **推荐匹配**的历史案例及相关产品资料（供销售审核）  
4. **生成英文**项目介绍、客户邮件和方案初稿  
5. **输出协同任务**：产品、设计、供应链、财务等部门待办  
6. **整理会议纪要**、跟进计划与商机风险  
7. **沉淀优秀方案**为团队知识（审核后入库）  

### 系统对接目标

与 CRM 或现有业务系统对接后实现：

- 客户信息有记录  
- 销售动作有提醒  
- 项目资料可复用

## 预期价值

| 维度 | 价值点 |
|------|--------|
| 效率 | 减少查资料、整理邮件、做方案、写跟进的重复工作 |
| 响应 | 复杂海外项目前期响应：数天 → 数小时（目标） |
| 协同 | 跨部门信息同步更快，减少遗漏与重复沟通 |
| 组织 | 降低个人经验依赖，新人更快掌握产品与项目经验 |
| 资产 | 沉淀海外市场知识，支撑本地化、方案化、数字化出海 |
| 推广 | 可复制到国内工程、整装、卫浴、大客户销售 |

## 需要支持（资源与协作）

### 数据侧

- 海外产品资料  
- 历史项目案例  
- 认证文件  
- 品牌素材  
- 报价及交付规则  

### 业务侧

国际销售、设计、产品、供应链、财务人员参与：

- 业务梳理（场景、话术、审核标准）  
- 试用反馈（准确性、可用性、协同流程）  

### 系统侧（条件允许）

- CRM 接口  
- 知识库 / 内部文件系统接口

## 与 FastGPT 的适配关系

|----------|------------------|
| 海外业务知识库 | 知识库 / 数据集（文档导入、向量检索、权限） |

| 协同任务拆解 | 工作流分支 + 固定输出模板 |
| 会议纪要与跟进 | 专用应用或工作流模板 |
| 知识沉淀 | 人工审核后回写知识库 |
| CRM 对接 | HTTP 插件 / API / 后续自定义对接 |
